# Theme reference

Read the theme used by the current task. Each file contains its foundations, light/dark CSS variables, and component assignments. Use these values to define the receiving app’s theme; intentional local customizations take precedence afterward.

- [Jamming](themes/jamming.md) — the active theme (“Sketchbook”), with two documented alternative configurations
- [Untitled](themes/untitled.md) — the kit’s original reference snapshot; its fonts (GT Standard M, Geist Mono) and palette are not used here
