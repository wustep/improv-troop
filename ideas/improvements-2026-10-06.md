## Technical

### 1. Cancel model calls on the server, not just in the browser
- **Impact:** 🔴 high · **Effort:** S · **Status:** ✅ accepted
- **Problem.** `src/app/api/llm/route.ts` passes only `AbortSignal.timeout(100_000)` to `generateText` and never uses `req.signal`. Cancel in `src/state/store.ts` only aborts the browser `fetch` (`src/ai/llm.ts`). The model call keeps running and billing the user's gateway key for up to 100 s, with up to 6 calls in flight.
- **Proposal.** Pass `AbortSignal.any([req.signal, AbortSignal.timeout(...)])`, skip the plain-text fallback once aborted, and return 499 on abort instead of 502.
- **Risks / trade-offs.** Depends on the platform passing client disconnects through to `req.signal`. If it doesn't, nothing changes.
- **Files.** `src/app/api/llm/route.ts`

### 2. callLLM abort handling: cancels reported as errors, backoff that can't be interrupted, listener leak
- **Impact:** 🟡 med · **Effort:** S · **Status:** ❌ rejected
- **Problem.** In `src/ai/llm.ts`, aborting during retry backoff throws the stale HTTP error rather than an AbortError, and the sleep ignores the signal. The `acquire()` abort listener is never removed. `res.json()` crashes on an HTML 504 page.
- **Proposal.** Add an `abortableSleep`, throw AbortError on abort, use `{ once: true }` and remove the listener, and guard the JSON parse.
- **Risks / trade-offs.** Low.
- **Files.** `src/ai/llm.ts`, `src/ai/pipeline.test.ts`

### 3. Takes persistence: one cap, quota-aware saving, shape-checked load
- **Impact:** 🟡 med · **Effort:** S · **Status:** ❌ rejected
- **Problem.** `store.ts` keeps 12 takes in memory but `saveTakes` writes 8 (3 if storage is full), so takes are lost on reload without warning. `loadTakes` casts without validation.
- **Proposal.** Add one `MAX_TAKES` constant, drop takes one at a time when the quota is hit, show a warning, and shape-check takes on load.
- **Risks / trade-offs.** Has to keep reading existing `jamming:takes:v1` data.
- **Files.** `src/state/store.ts`, `src/components/Transport.tsx`

### 4. One shared note-shaping function for audio and animation
- **Impact:** 🟡 med · **Effort:** M · **Status:** ❌ rejected
- **Problem.** Articulation and duration rules are written twice, in `src/audio/engine.ts` `scheduleNote` and in `src/components/stage/frames.ts`. The two copies have drifted: frames has no legato or decay handling, and its pizz cap ignores rit.
- **Proposal.** Add `shapeNote()` in `src/audio/feel.ts`, use it from both places, and test it.
- **Risks / trade-offs.** Small timing changes in the rigs.
- **Files.** `src/audio/engine.ts`, `src/components/stage/frames.ts`, `src/audio/feel.ts`

### 5. Skip no-op SVG writes in the sprite Bag
- **Impact:** 🟡 med · **Effort:** S · **Status:** ❌ rejected
- **Problem.** `Bag.tf/op/set` (`src/art/rigs/types.ts`) write to the DOM every frame for every animal even when the value hasn't changed. That is hundreds of mutations per frame.
- **Proposal.** Cache the last value and return early when it hasn't changed.
- **Risks / trade-offs.** A direct DOM write outside the Bag would leave the cache stale.
- **Files.** `src/art/rigs/types.ts`, `src/art/AnimalSprite.tsx`

## UI/UX & Design

### 6. Readable primary buttons: white on hatched fill fails contrast
- **Impact:** 🔴 high · **Effort:** S · **Status:** ➖ superseded: PR #1 (Graphical/Sketchbook theme, merged mid-loop) already gave primary/go buttons solid washes with on-accent labels
- **Problem.** The `RoughButton` `primary`/`go` tones (`src/components/ui/rough.tsx`) draw a hachure fill with paper showing through, under `text-white` labels ("Let them jam!", ▶). Contrast is well below 3:1 on the app's most important controls.
- **Proposal.** Add a solid darker underlay beneath the hatching (hatch stays on top for texture), plus a subtle text shadow in the same shade.
- **Risks / trade-offs.** Looks slightly less "pencil".
- **Files.** `src/components/ui/rough.tsx`

### 7. Error and loading states that offer a next step
- **Impact:** 🔴 high · **Effort:** M · **Status:** ✅ accepted (in place of #6)
- **Problem.** Errors are red status text with no retry (`Transport.tsx`). The load meter is `aria-hidden`. The chart header renders with no score. The sheet placeholder `#a49c8c` is about 2.5:1.
- **Proposal.** A dismissible error card with "try again" and "play the sketch", a progressbar role, a gated chart header, and a darker placeholder.
- **Risks / trade-offs.** Retry needs the last request kept.
- **Files.** `src/components/Transport.tsx`, `src/app/page.tsx`, `src/sheet/SheetMusic.tsx`

### 8. FormMap as a keyboard scrubber with a transform-based playhead
- **Impact:** 🔴 high · **Effort:** M · **Status:** ❌ rejected
- **Problem.** One `<button>` per bar means 64 tab stops and roughly 5px touch targets on phones. The playhead animates `left`.
- **Proposal.** Turn the strip into a single `role="slider"` with arrow, Home/End and PageUp/PageDown keys, seek on pointer `clientX`, and move the playhead with `translateX`.
- **Risks / trade-offs.** Loses the per-bar native tooltips.
- **Files.** `src/components/FormMap.tsx`

### 9. Show when sheet follow-scroll is off and let users turn it back on
- **Impact:** 🟡 med · **Effort:** S · **Status:** ❌ rejected
- **Problem.** Scrolling the chart by hand quietly turns off follow until the next Play (`SheetMusic.tsx`).
- **Proposal.** A sticky "↓ back to the band" pill while playing and not following.
- **Risks / trade-offs.** Positioning inside the scroller.
- **Files.** `src/sheet/SheetMusic.tsx`

### 10. Correct ARIA semantics on chip groups and RoughButton
- **Impact:** 🟡 med · **Effort:** S · **Status:** ❌ rejected
- **Problem.** `RoughButton` puts `aria-pressed` on every button. Single-choice chip groups aren't radio groups. There are two controls named "Mode". The tempo slider has no `aria-valuetext`.
- **Proposal.** Make `aria-pressed` opt-in, use radiogroup/radio with roving focus, fix the labels, and add valuetext.
- **Risks / trade-offs.** Changes the Tab order.
- **Files.** `src/components/ui/rough.tsx`, `src/components/ControlPanel.tsx`

## Product Features

### 11. Band talk without a key: narration from the plan
- **Impact:** 🔴 high · **Effort:** S · **Status:** ✅ accepted
- **Problem.** Local takes set `chat: []` (`src/music/local.ts`, `src/state/store.ts`), so on the default no-key path BandTalk is empty and the stage speech bubbles never appear.
- **Proposal.** `narrateLocal()` builds short seeded template lines with bar stamps from `frame.sections`, the leader, solos and the ending. Called from `generateLocal`.
- **Risks / trade-offs.** Lines have to match what is actually played, so they come from the frame and plan only.
- **Files.** new `src/music/narrate.ts`, `src/music/local.ts`, `src/state/store.ts`

### 12. Share a take as a URL (seeded replay)
- **Impact:** 🔴 high · **Effort:** M · **Status:** ✅ accepted
- **Problem.** Takes live only in localStorage. Local takes can be rebuilt exactly from settings, members and seed, but there's no way to send one.
- **Proposal.** A versioned `#t=` hash payload. Hydrate decodes and validates it, then rebuilds with `generateLocal`. A share button copies the link (or uses `navigator.share`). Hidden for AI takes.
- **Risks / trade-offs.** Engine changes alter how old links play back. Input from the link is untrusted and has to be validated and clamped.
- **Files.** new `src/state/share.ts`, `src/state/store.ts`, `src/components/Transport.tsx`

### 13. Export MIDI
- **Impact:** 🔴 high · **Effort:** M · **Status:** ❌ rejected
- **Problem.** No export of any kind, though `NoteEvent` is already MIDI-clean.
- **Proposal.** A pure type-1 SMF writer, one track per member, drums on channel 10, with a download link.
- **Risks / trade-offs.** GM program choices are rough.
- **Files.** new `src/music/midi.ts`, `src/components/Transport.tsx`

### 14. Loop a section for practice
- **Impact:** 🟡 med · **Effort:** M · **Status:** ❌ rejected
- **Problem.** `TroopAudio.play` has a `loop` option that no caller uses, and it can't loop just one section.
- **Proposal.** Bar-range looping, toggled from FormMap or Transport.
- **Risks / trade-offs.** Conflicts with the improviser watchdog.
- **Files.** `src/audio/engine.ts`, `src/components/FormMap.tsx`

### 15. Visible seed: "again", re-roll and variations
- **Impact:** 🟡 med · **Effort:** S · **Status:** ❌ rejected
- **Problem.** Every generate picks a new random seed (`store.ts`), and the seed only appears in debug notes.
- **Proposal.** A seed chip with again, re-roll and variation actions.
- **Risks / trade-offs.** Clutters the UI.
- **Files.** `src/state/store.ts`, `src/components/Transport.tsx`

## DevEx

### 16. typecheck/check scripts and a GitHub Actions CI workflow
- **Impact:** 🔴 high · **Effort:** S · **Status:** ✅ accepted
- **Problem.** There is no typecheck script and no `.github/`, so nothing runs lint, types or tests before a Vercel deploy.
- **Proposal.** Add `typecheck` and `check` scripts, plus `.github/workflows/ci.yml` (pnpm, Node 22, frozen lockfile).
- **Risks / trade-offs.** Need to make sure tsc doesn't rely on generated `.next/types`.
- **Files.** `package.json`, `.github/workflows/ci.yml`

### 17. Direct unit tests for reharm.ts and ending.ts
- **Impact:** 🔴 high · **Effort:** S · **Status:** ❌ rejected
- **Problem.** These are the most recently changed engine modules, and they're only tested end to end through `generateLocal`.
- **Proposal.** Invariant tests: strength 0 changes nothing, bars outside the range are untouched, seeded determinism, symbols parse, and every style has an ending.
- **Risks / trade-offs.** Tests that pin exact chords would break on taste tweaks, so test invariants instead.
- **Files.** new `src/music/reharm.test.ts`, `src/music/ending.test.ts`

### 18. Cross-style invariant sweep over generateLocal
- **Impact:** 🔴 high · **Effort:** M · **Status:** ❌ rejected
- **Problem.** No single test checks global invariants across styles × standards × lengths × seeds.
- **Proposal.** `invariants.test.ts` checking range, finite timing, chords that parse, and standards whose form adds up to their bar count.
- **Risks / trade-offs.** Runtime.
- **Files.** new `src/music/invariants.test.ts`

### 19. Seeded golden snapshots for the engine
- **Impact:** 🟡 med · **Effort:** S · **Status:** ❌ rejected
- **Problem.** The determinism test only compares two runs inside one process, so it can't catch the music changing between commits.
- **Proposal.** Digest snapshots, one per style.
- **Risks / trade-offs.** Snapshots need updating whenever the music changes on purpose.
- **Files.** new `src/music/golden.test.ts`

### 20. Real AGENTS.md architecture notes and a play-through guide
- **Impact:** 🟡 med · **Effort:** S · **Status:** ❌ rejected
- **Problem.** AGENTS.md only has the Next.js boilerplate. `window.__jamming` and the mock key aren't documented for agents.
- **Proposal.** A module map, the data flow, determinism rules, and how to drive a play-through.
- **Risks / trade-offs.** Docs go stale.
- **Files.** `AGENTS.md`
